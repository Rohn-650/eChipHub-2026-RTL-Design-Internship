
# RTL Synthesis using Yosys

## Overview

Designed and synthesized a **2:1 Multiplexer** using the open-source **Yosys (RTL Synthesis)** suite. This project demonstrates the industrial digital design translation flow, showing how behavioral Verilog HDL descriptions are optimized, mapped, and translated into a structurally accurate, technology-mapped **gate-level netlist** using standard cells from the **OSU 0.18µm library** (`osu018_stdcells.lib`).

## Description

Logic synthesis acts as the bridge between software-style hardware description languages (RTL) and physical gate-level silicon logic. 

In this lab, a basic 2:1 Multiplexer is described behaviorally. The multiplexer acts as a data routing switch, forwarding input `b` to the output `out` when the select signal `sel` is high, and forwarding input `a` when `sel` is low. This behavior is mathematically represented as:
$$\text{out} = (\text{sel} \cdot b) + (\overline{\text{sel}} \cdot a)$$

The Yosys tool reads this design, performs register-transfer level (RTL) optimizations, and then maps the abstract logic onto physical cell models defined in the standard liberty cell library (`osu018_stdcells.lib`). 

The resulting mapped gates (including `INVX1` inverters, `NAND2X1` NAND gates, or complex `OAI21X1`/`AOI21X1` And-Or-Invert structures) preserve the exact functional truth table of the multiplexer while optimizing layout area and circuit timing paths.

## Synthesis Design and Execution Flow

### 1. Behavioral RTL Code (`mux_2x1.v`)
```verilog
// 2:1 Multiplexer - Behavioral Modeling
// Continuous assignment modeling a conditional operator
`timescale 1ns/1ps

module mux_2x1 (
    input  wire a,      // Input Data 0
    input  wire b,      // Input Data 1
    input  wire sel,    // Select Control Line
    output wire out     // Routed Output
);

    assign out = sel ? b : a; // Select b if sel=1, else select a

endmodule
```

### 2. Yosys Synthesis Script (`synth_script.ys`)
To automate synthesis mapping, Yosys interprets specific optimization scripts:
```yosys
# Read the Verilog RTL source design
read_verilog mux_2x1.v

# Parse design hierarchy and verify top-level module ports
hierarchy -check -top mux_2x1

# Translate processes and perform high-level RTL optimizations
proc; opt; map; opt;

# Technology map logic blocks to internal virtual gate library
techmap; opt

# Map design registers (flip-flops) to OSU library cells
dfflibmap -liberty osu018_stdcells.lib

# Map combinational logic paths to standard cells via ABC engine
abc -liberty osu018_stdcells.lib

# Clean up unused wires, dangling signals, and dead cells
clean

# Write the final optimized gate-level structural Verilog netlist
write_verilog mux_2x1_synth.v

# Generate a graphical schematic diagram of the mapped netlist
show
```

## Results

### 1. Synthesized Gate-Level Netlist (`mux_2x1_synth.v`)
After executing Yosys, the behavioral conditional statement is parsed and translated into physical standard-cell gates. Below is the technology-mapped netlist generated by the tool:

```verilog
/* Generated by Yosys 0.xx */
// Mapped to Oklahoma State University (OSU) 0.18um Standard Cells
`timescale 1ns/1ps

module mux_2x1(a, b, sel, out);
  input a;
  wire a;
  input b;
  wire b;
  output out;
  wire out;
  input sel;
  wire sel;
  wire _0_;
  wire _1_;

  // Inverter: Inverts the select line
  INVX1 _2_ (
    .A(sel),
    .Y(_0_)
  );

  // NAND Gate: Maps input data 'b' and select line
  NAND2X1 _3_ (
    .A(b),
    .B(sel),
    .Y(_1_)
  );

  // Or-And-Invert (OAI) Cell: Performs optimized logic mapping
  // Calculates: out = !((_0_ | _1_) & a) which matches 2:1 multiplexer logic
  OAI21X1 _4_ (
    .A(_0_),
    .B(_1_),
    .C(a),
    .Y(out)
  );

endmodule
```

## Learning Outcome

* **RTL-to-Netlist Compilation**: Mastered logic compilation fundamentals, converting abstract behavioral syntax into physical hardware equations.
* **Technology Mapping**: Learned how optimization synthesis tools utilize Liberty files (`.lib`) to target specific cell nodes and gate limits.
* **Standard Cell Layout Logic**: Investigated optimized logic architectures like Or-And-Invert (`OAI21X1`) and NAND arrays instead of raw discrete gates.

* **Schematic Visualization Analysis**: Utilized internal visualization frameworks to verify physical path layouts against logical intent.
