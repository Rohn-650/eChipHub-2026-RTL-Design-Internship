# RTL Design

This section covers the implementation and verification of fundamental digital circuits using Verilog HDL. The designs were simulated using Verilator and analyzed using GTKWave.

## Projects

### AND Gate

Implementation and verification of a 2-input AND gate.

### 4x1 Multiplexer

Design and verification of a 4-to-1 multiplexer using combinational logic.

### Half Adder

Implementation of a Half Adder for basic arithmetic operations.

### Counter

Design and simulation of sequential counter circuits.

## Tools Used

* Verilog HDL
* Verilator
* GTKWave

## Learning Outcomes

* Verilog module development
* Combinational logic design
* Sequential logic design
* Testbench creation
* RTL simulation and waveform analysis
